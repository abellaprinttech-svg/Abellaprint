# Abella Print Tech

Soluciones en Manufactura Aditiva e Impresión 3D de alta precisión.

## 🚀 Descripción

**Abella Print Tech** es una aplicación web interactiva que ofrece:
- **Visualizador 3D interactivo**: Carga y renderizado de modelos 3D (`.STL`, `.OBJ`, `.3MF`, `.STEP`, `.STP`, `.IGES`, etc.) con controles de rotación, zoom y visualización.
- **Catálogo de productos para particulares**: Selección y filtrado de productos organizados por categorías (Fundas y Soportes, Llaveros, Figuritas, Cocina y Hogar, Bolis y Escritorio).
- **Subida y análisis de modelos 3D**: Guardado local (IndexedDB / SessionStorage) para inspección inmediata antes de enviar o cotizar.

## 🛠️ Tecnologías

- **HTML5 / CSS3**: Diseño moderno, responsivo y adaptado para dispositivos móviles y de escritorio.
- **JavaScript (ES6+)**: Interacción dinámica, carga de archivos y gestión de almacenamiento en el navegador.

## 💻 Cómo ejecutar localmente

Puedes abrir directamente el archivo `index.html` en cualquier navegador web moderno, o usar una extensión de servidor local como *Live Server* en Visual Studio Code:

1. Clona el repositorio:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd Abellaprint.tech
   ```
2. Abre `index.html` en tu navegador favorito.
